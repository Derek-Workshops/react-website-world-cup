# Break Point — A Tennis Podcast Website

A single-page React + TypeScript website for **Break Point**, a fictional weekly
tennis podcast. Built with Create React App and styled with Tailwind CSS.

## Pages

- **Home** — hero, latest episode with a working audio player, show stats, featured episodes, and a subscribe call-to-action.
- **Episodes** — the full episode library with tag filtering and per-episode audio players.
- **Hosts** — meet the three hosts of the show.
- **About** — what the show is about, stats, and a newsletter subscribe form.

All content (episodes, hosts, stats) is placeholder data in `src/data/mockData.ts`.
The audio players use a royalty-free sample track so the play buttons actually work.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.
